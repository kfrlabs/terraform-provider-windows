# windows Provider

The windows provider manages Windows resources over SSH (the target host's OpenSSH Server, invoking PowerShell). Host key verification is not performed; only use this against trusted, short-lived automation hosts.

## Example Usage

```terraform
terraform {
  required_providers {
    windows = {
      source  = "kfrlabs/windows"
      version = "~> 0.0"
    }
  }
}

provider "windows" {
  host     = var.windows_host
  username = var.windows_username
  password = var.windows_password
}
```
